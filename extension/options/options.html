LoonieWins Autofill

Configure how the extension syncs your giveaway profile. Use the anon (publishable) Supabase key only — never service_role.

Supabase (optional)

When you are signed into LoonieWins, the extension can copy your session from the app tab and fetch profiles.auto_fill_data with RLS. Without auth, sync from localStorage (looniewins_autofill) still works.

Install & use

  1. Open chrome://extensions (or Edge equivalent).
  2. Enable Developer mode → Load unpacked → select this extension/ folder.
  3. Run LoonieWins locally, save Profile autofill (key looniewins_autofill), then click Sync from LoonieWins tab.
  4. Open a giveaway form → click the extension → Fill this page (or Alt+Shift+L / right-click menu).

To sync from a hosted LoonieWins origin, add that host under the extension’s site access (Chrome → Extension details → Site access) or extend content_scripts.matches in manifest.json.

Security

  • This extension rejects keys whose JWT role is service_role.
  • Only the anon key + your user access token are stored in chrome.storage.local.
  • Password fields are never autofilled.
  • Fill runs only when you trigger it (popup, shortcut, or context menu) via activeTab.
